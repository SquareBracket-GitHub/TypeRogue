# Privacy Notice

English | [한국어](PRIVACY.ko.md)

TypeRogue does not collect or transmit personal data.

The extension reads the names, forms, and types of Pokémon displayed in the current PokeRogue battle to calculate defensive matchups. This information remains in the current browser tab and is neither transmitted nor stored permanently.

The browser's extension-local storage stores only:

- Panel position
- Panel collapsed state
- Development logging preference

You can remove these settings by deleting the extension's data in Firefox or Chrome, or by clicking the panel's reset button. TypeRogue contains no analytics, advertising SDK, remote tracking code, or developer-operated server.

TypeRogue's use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information read from the current PokeRogue battle is used only to provide the extension's defensive type-matchup feature, is not transferred to third parties, and is not used for advertising or credit-related purposes.
