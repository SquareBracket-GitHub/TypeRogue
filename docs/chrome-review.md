# Chrome Web Store 검토 안내

## 단일 목적

TypeRogue의 단일 목적은 PokeRogue 전투 중 아군과 상대 포켓몬의 방어 타입 상성을 화면에 표시하는 것입니다. 자동 감지, 수동 선택, 패널 위치 저장은 모두 이 목적을 직접 지원합니다.

## 권한 사유

- `storage`: 패널 위치, 접힘 상태와 개발 로그 설정을 브라우저 내부에 저장합니다.
- `https://pokerogue.net/*`: PokeRogue 전투 상태를 읽고 타입 상성 패널을 표시하기 위해 이 사이트에서만 content script를 실행합니다.

탭, 방문 기록, 쿠키, 계정, 외부 네트워크 접근 권한은 요청하지 않습니다.

## 데이터 처리

현재 전투의 포켓몬 이름·폼·타입은 사용자가 보는 타입 상성을 계산하기 위해 현재 탭에서만 처리합니다. 해당 전투 정보는 저장하거나 전송하지 않습니다. UI 설정만 확장 전용 로컬 저장소에 보관합니다. 분석, 광고, 추적, 자체 서버와 원격 실행 코드는 없습니다.

Chrome 웹 스토어 개발자 대시보드에는 이 설명과 `PRIVACY.md`의 내용이 서로 일치하도록 입력해야 합니다. 웹사이트 콘텐츠를 로컬에서 읽는 동작도 데이터 취급으로 신고 대상이 될 수 있으므로, 전투 화면 정보의 로컬 처리 사실을 숨기지 않습니다.

## 검토자가 확인할 기능

1. Chrome에서 PokeRogue를 열고 전투를 시작합니다.
2. 오른쪽 위 패널에 아군과 상대 포켓몬의 방어 타입 상성이 표시되는지 확인합니다.
3. 포켓몬 교체, 폼 변화, 싱글·더블 전투에서 패널 갱신을 확인합니다.
4. 패널 이동, 접기, 초기화와 자동 감지 실패 시 수동 선택을 확인합니다.

로그인이나 유료 계정은 필요하지 않습니다. 실제 전투 진입이 어려운 경우 검토자가 기능을 재현할 수 있도록 스토어 제출 메모에 구체적인 시험 절차를 적습니다.
