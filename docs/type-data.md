# 타입 및 포켓몬 데이터 정책

- 18개 타입 상성표와 계산기는 확장에 포함되며 네트워크 요청을 하지 않는다.
- 타입 배지는 TypeRogue에서 직접 만든 문자·원형 기반 표현이다. 외부 아이콘 자산이나 Pokémon 상표 이미지를 재배포하지 않는다.
- 포켓몬 객체의 `getTypes({ includeTeraType: false, bypassSummonData: true, ignoreThirdType: true })` 결과가 최우선이다. 따라서 일반종, 지역 폼, 메가진화 등 명시적 폼과 융합의 현재 타입은 게임의 실제 값으로 계산된다.
- 로컬 폼 표는 런타임 값을 얻지 못했을 때만 쓰는 제한적 안전망이며, 대표 일반종·지역 폼·타입 변경 특수 폼을 포함한다.
- 융합 폴백은 본체의 첫 타입을 유지하고 융합 재료에서 중복되지 않는 첫 타입을 두 번째 타입으로 선택한다. 런타임 `getTypes()`가 있으면 이 규칙보다 그 값을 우선한다.
- 기술·특성·테라스탈 등에 의한 일시적 타입 변경은 MVP 범위에서 제외한다.
